# Pocket Defense

An original, lightweight 2D tower-defense browser game built with HTML, CSS, and JavaScript. It is inspired by the broad tower-defense genre, with original names, visuals, UI, and game code.

## Play locally
Open `index.html` in a modern browser. No build step or dependencies are required.

## Publish on GitHub Pages
1. Create or open a GitHub repository.
2. Upload `index.html`, `style.css`, and `game.js` to the repository root.
3. In **Settings → Pages**, choose **Deploy from a branch**, select your main branch and `/ (root)`, then save.
4. Wait for the Pages deployment and open the URL GitHub provides.

## Gameplay
- Five tower types: Dartling, Tack Sprayer, Pine Sniper, Frost Fern, and Acorn Cannon.
- 40 rounds with progressively tougher and faster blobs, including swift, heavy, and armored variants.
- Tower upgrades, selling, range previews, cash, lives, pause, speed controls, sound effects, and local auto-save.
- Saved progress is stored in the browser's local storage on that device/browser.

## Notes
This is a playable first version, not a clone of Bloons TD 6. It uses simple canvas-drawn original shapes and does not include online multiplayer or cloud saves.
